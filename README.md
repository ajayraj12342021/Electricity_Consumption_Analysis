# Household Electricity Consumption Analysis

## Project Overview
This project analyzes electricity consumption and estimated bills for five households from January to June 2026 using Excel, MySQL, and Power BI.

## Tools Used
- Microsoft Excel
- MySQL
- Microsoft Power BI

## Key Findings
- Total Consumption: 7,590 kWh
- Total Estimated Bill: ₹45,540
- Highest Consumption: H004 (1,890 kWh)
- Lowest Consumption: H003 (1,130 kWh)

## Features
- Monthly electricity consumption analysis
- Household-wise consumption and bill comparison
- Interactive dashboard with charts, KPI cards, and slicers
